## Commands

### Quick Zip Folder

PowerShell

```powershell
Compress-Archive -Path .\<filename> -DestinationPath .\zips\<filename>.zip -Force
```

Ubuntu:

```bash
zip -r zips/<filename>.zip <filename>
```
